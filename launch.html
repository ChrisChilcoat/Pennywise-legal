Launch Pennywise

Pennywise is a personal bookkeeping app that runs on the developer's own computer, not on this website.

  1. On that computer, open a terminal in the Pennywise folder.
  2. Run npm.cmd run auth to start the local app.
  3. Open http://localhost:8000/.

Need to connect QuickBooks first? See Connect or reconnect.

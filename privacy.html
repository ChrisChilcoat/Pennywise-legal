Pennywise Privacy Policy

Effective November 15, 2026

About Pennywise

Pennywise is a personal bookkeeping tool built and run by one individual developer for their own use. It connects to the developer's own QuickBooks Online company through Intuit's APIs. It is not offered, sold, or made available to anyone else.

Information Pennywise accesses

When the developer authorizes Pennywise, Intuit grants access to these scopes:

  • QuickBooks Online Accounting (com.intuit.quickbooks.accounting): company information and accounting records.
  • QuickBooks Payments (com.intuit.quickbooks.payment): payment and charge records.
  • OpenID Connect profile (openid profile email phone address): the name, email, phone number, and address on the authorizing Intuit account.

How it is used

Data is used only to show and manage the developer's own bookkeeping. Pennywise does not use the data for advertising, profiling, or any purpose unrelated to that bookkeeping.

Human review of every change

Pennywise never changes QuickBooks data on its own. Every change goes through review first, whether the developer started it or AI suggested it. Changes include creating, updating, or deleting records and processing payments. Pennywise shows each change to the developer, and nothing is sent until the developer approves that specific change. Pennywise has no automatic or unattended writes.

AI processing

Pennywise uses a generative AI model, Anthropic's Claude, accessed through the Claude API, to help with bookkeeping tasks. These tasks include categorizing transactions, summarizing accounting data, and answering questions about the developer's own books.

  • When data is sent: only when the developer starts one of these tasks.
  • What is sent: only the QuickBooks records the task needs, such as transaction details, account names, and amounts. OAuth tokens and app credentials are never sent.
  • Review: AI output is only a suggestion. A suggested change reaches QuickBooks only after the developer approves it, as described under Human review of every change.
  • No training: Pennywise does not use QuickBooks data to train or fine-tune any AI model.
  • Provider terms: Anthropic processes data sent to the Claude API under its own Commercial Terms and Privacy Policy.

Storage and security

  • Pennywise runs on the developer's own computer. OAuth access and refresh tokens are stored locally and are never committed to source control.
  • The app's client secret is loaded from a local environment variable and is never published.
  • QuickBooks data is retrieved on demand. It is not copied to any external server or database operated by Pennywise. The only exception is the per-task requests to the Claude API described above.

Sharing

Pennywise does not sell or rent QuickBooks data or personal information. Data passes only between the developer's computer, Intuit's services, and Anthropic's Claude API as described under AI processing.

If Pennywise is later changed to send QuickBooks data to any other service, this policy will be updated to name that service before the change is made.

Retention and deletion

Tokens are kept until access is revoked or they expire. To end access at any time, disconnect Pennywise from the QuickBooks company's connected apps settings, or delete the locally stored token file. Either action stops all further data access.
